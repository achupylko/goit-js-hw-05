# GoIT Homework — JavaScript Module 5

## 📘 Опис проєкту

Цей репозиторій містить п’яте домашнє завдання з модуля **JavaScript** курсу  
**Fullstack Developer** від **GoIT**.  
Мета роботи — навчитися працювати з **callback-функціями**, **стрілочними
функціями** та **вбудованими методами масивів** для ефективної обробки даних.

---

## 🎯 Цілі модуля 5 (JavaScript)

- Розуміти принцип роботи **callback-функцій** та передавання функцій як
  аргументів.
- Використовувати **стрілочні функції (arrow functions)** та знати їх
  відмінності від звичайних функцій.
- Працювати з методами масивів:
  - `map()` і `flatMap()`
  - `filter()` і `find()`
  - `every()`, `some()` і `reduce()`
- Застосовувати метод **`toSorted()`** для створення відсортованих копій масивів
  без мутації оригіналу.
- Формувати **чисті та читабельні функції** з використанням сучасного синтаксису
  ES6+.
